## What this note contributes

A successful-looking output is insufficient evidence that an implementation performed the required synchronization. A useful assessment connects the exact probe, the causal mechanism, a discriminating negative control and the assessor's actual decision. This is the methodological proposition P01.

One narrow historical example, P02, is described from retained internal records: an experimental immediate-timeout variant printed a PASS label and exited through the project's favorable process/emulator route, while a structural validator rejected the missing blocking path. The underlying logs, programs and private working archives are **not included**. Their selected hashes are evidence commitments in [CLAIMS_AND_EVIDENCE.md](CLAIMS_AND_EVIDENCE.md), not a public reproduction kit or proof of authenticity.

The text also proposes how a future comparative study could separate functional capability, development effort and economic effects. It reports no causal estimate of AI productivity or innovation incentives.

## Scope and current state

This is a **text-only partial research note**. It contains no implementation code, binary, firmware, raw experiment log, private correspondence or executable workflow. It does not distribute Windows, QEMU, EDK2, MinGW or private project artifacts.

The historical I5 campaign remains closed with explicit holds. Its J3/J4 observations are partial and tied to that revision. The later T09 normal EFI image is recorded as built but never booted; its global-error-state mutant remains unbuilt and unrun. Two-waiter coverage, independently calibrated API timing, reserved cases and completion of the planned, bounded negative-control set remain open. **J5 is not acquired; `BOUNDED_PASS=false`; the native/guest gate remains HOLD.** I20 performs documentary work only and adds no experiment to those technical results.

The note does not claim general Windows compatibility, a Windows clone, Intel conformance, proven infringement, a general legal permission for reverse engineering or institutional endorsement. Similar functionality alone establishes none of those conclusions.
